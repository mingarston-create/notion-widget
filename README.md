GitHub Pages отдаёт интерфейс по HTTPS. Сервис из каталога [`_server`](_server) работает с приватными базами Notion напрямую через `api.notion.com`. Страницы встраиваются в Notion по ссылкам из таблицы.

## Подключение сервиса данных

В [`widget-config.js`](widget-config.js) задан постоянный адрес `https://notion-widgets-api.mingarston.workers.dev`. Cloudflare Worker передаёт запросы к закрытому VPS через Workers VPC и исходящий Cloudflare Tunnel. При смене IP восстановите сервис, SQLite и подключение того же туннеля к Cloudflare. Адрес API и ссылки внутри Notion сохраняются. Исходник Worker находится в [`_server/cloudflare-worker.js`](_server/cloudflare-worker.js).

Сервис слушает `127.0.0.1:8080`. HTTPS-вход должен передавать заголовок `Authorization` и запросы `OPTIONS`, `GET` и `POST` к `/api/`. Для страниц разрешён источник `https://mingarston-create.github.io`.

- Разместите исходники привычек и задач в `/opt/habits_api`, а `donation/sync.py` — в `/opt/notion-widgets/donation`. Описание служб и таймеров находится в [`_server/systemd`](_server/systemd).
- Восстановите `/var/lib/notion-habits/journal.sqlite3` из резервной копии. Сверьте даты, историю и ожидающие отправки операции перед запуском синхронизации.
- Заполните `/etc/notion-habits/config.json` по [образцу](_server/config.example.json). Идентификаторы баз, опций, полей и прежних названий привычек берутся из старой конфигурации и исходников резервной копии. Токен Notion и ключи виджетов хранятся на сервере.
- К приватным ссылкам в Notion добавьте фрагмент `#key=…`. Для привычек, статистики и задач используйте значение `api_key`, для донорства — отдельное значение `donation_api_key`. Фрагмент не отправляется в GitHub Pages. Ключ передаётся сервису данных в заголовке, а токен Notion остаётся в серверной конфигурации.

## Часовой пояс привычек и задач

При запуске API читает необязательный параметр `tracker_timezone` из серверной конфигурации, например `Europe/Moscow`. Без параметра сервис продолжает использовать пояс, сохранённый в журнале. Для нового журнала действует Москва. Учётный день начинается в 03:00 по выбранному поясу.

Для смены пояса укажите название зоны IANA и перезапустите службу API. История настроек позволяет доставить офлайн-отметку с датой, которую виджет сохранил при нажатии. Для полного обновления разверните страницы GitHub Pages, службу API и Cloudflare Worker. Обновление серверного маршрута закрывает запись настроек из старых вкладок.

## Работа при пропадании связи

После первой загрузки каталога на устройстве отметка меняется сразу. Локальная очередь IndexedDB сохраняет действие и дату. Виджет повторяет отправку, пока сервис не подтвердит запись. Одинаковый идентификатор операции позволяет сервису обработать повтор без дубля. Отдельный статус показывает, когда запись сохранена на устройстве, принята сервером или синхронизирована с Notion.

Страницы привычек на GitHub Pages используют одну очередь в рамках доступного им хранилища браузера. У старой страницы «День / Вечер» был другой адрес и отдельное хранилище. Если там оставались неотправленные действия, их нужно сверить перед заменой ссылки.
